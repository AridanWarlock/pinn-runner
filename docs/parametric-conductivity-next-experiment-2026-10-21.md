# Один следующий опыт: одна сеть для разных c(x)

Это предложение следующего ограниченного CUDA-опыта, **не готовый машинный
протокол очереди и не состоявшееся обучение качества**. Выбор следует из
[результатов TASK-38](parametric-conductivity-result-2026-10-21.md).
Нечётное представление Бюргерса отложено: текущий приоритет — входные
функции коэффициента.

## Проверяемый вопрос

Может ли одна сеть с общими весами решить семейство диффузии без источника
для коэффициента exp(a cos(pi x)+b cos(2pi x))/8 на всём заданном квадрате
параметров, сохранив абсолютное качество на заранее выбранных срезах?

Постановка, IC/BC, область и время строго совпадают с
[CPU-протоколом](parametric-conductivity-protocol-2026-10-21.md).
Сеть имеет входы x,a,b,t, 32³ и 2305 параметров; физическое поле задаётся
проверенным `Problem.transform`. Основной режим решателя прежний.

Каждое из состояний 11/29/83 обучает **одну** общую сеть. Нельзя обучать
13 сетей и назвать их одним оператором. Веса одной модели должны быть
неизменными при оценке всех материалов; сохранить общий SHA состояния.

## Предварительный допуск

До качества нужны численные CUDA-проверки четырёх сетевых сценариев,
включая оба отрицательных контроля, и малый файловый CUDA-цикл этого
Problem. Нужны регистрация семейства и параметрических метрик в прежнем
инструменте, проверки старых контрактов, полный CPU-набор, отдельные
опубликованные SHA кода и машинного протокола. CPU-подготовка не заменяет
этот допуск; запускать произвольную команду в обход очереди нельзя.

Эталон должен быть доступен на Windows в FP64 с теми же контролями
сходимости и резервным спектральным алгоритмом. Его реализация и источник
PDE фиксируются независимо. Текущая таблица из 325 значений недостаточна
для оценки качества поля и не служит обучающей выборкой.

## Фиксированный бюджет

FP32/highest, TF32 выключен, eager/recursive/all/general/identity.
8192 фиксированных LHS-точки в четырёхмерном пространстве x,a,b,t,
равномерные диапазоны из протокола. Раздельно сохранить хеш точек и
полный состав физики: одинаковые точки сами по себе не фиксируют PDE.

1000 шагов Adam с learning_rate=0.001, затем 1000 внешних L-BFGS;
срезы после Adam и после 250/500/1000 внешних шагов. Внутренние замыкания
и обработанные точки учитывать отдельно. Никакой адаптации бюджета после
результатов. Таймаут всей серии — 1200 секунд, без автоматического продления.
Малые файловые проверки допускаются отдельно и не считаются траекториями
качества. Начальные и граничные функции не являются скрытым эталоном поля.

Коллокационные значения a,b — непрерывные LHS, не только 9 узлов. Исходная
функция sin(pi x) одинакова для всех параметров. Ни спектральные значения
поля, ни их производные не поступают в функцию потерь. Механизм потерь
существующего soft+transform сохраняется и фиксируется в протоколе.

## Оценка и абсолютные цели

В каждом срезе оценить все 13 заранее выбранных параметров. Финально
дополнительно оценить 64 заранее сохранённые пары Sobol (seed 20261022),
всего 77 материалов на общих весах. [CSV параметров](experiments/2026-10-21-parametric-conductivity-holdout-parameters.csv)
имеет LF-нормализованный SHA256 `f7bd1b82af3a5389c8757a9b10d977b7e81c95738e3615e7059c5226080370bb`.
Эти дополнительные пары закреплены до какого-либо обучения качества.
Четыре
внутренние пары — дополнительные срезы интерполяции внутри обучаемой
области, не доказательство экстраполяции и не независимая выборка материалов.
Обучение не видит их эталонные поля. Значения новых параметров передаются
через существующий публичный параметрический вход; переобучения между
парами нет. `prediction.parameters` задаёт декартово произведение списков,
а не список пар: оценщик должен явно сохранять запрошенные пары и не
создавать неявное произведение 77×77. Прямое пакетное предсказание общей
сети допускает согласованные столбцы x,a,b,t.

Основная сетка x:1025, t:81, контрольная x:513, t:41, вложенные узлы.
Для нового временного разрешения эталон вновь проверить уточнением
пространственного оператора. Нормы поля и градиента — трапецеидальные
интегралы, не безымянное среднее массива. Производная независимого эталона —
центральная разность второго порядка с односторонним правилом второго
порядка на концах, как в проверенном CPU-контроле 77 материалов. Её
сходимость и точный постоянный случай проверяются до оценки сети.
Для каждой пары отдельно:

| Показатель | Верхний порог |
|---|---:|
| Относительный L2 поля по x,t | 0.002 |
| Относительный L2 при t=1 | 0.003 |
| Худший временной относительный L2 поля | 0.005 |
| Худший временной относительный L2 пространственной производной | 0.02 |
| Независимый физический PDE RMS | 0.003 |
| Начальный RMS | 1e-6 |
| Граничный максимум | 1e-6 |
| Разница относительных L2 двух сеток | 2e-5 |

Уточнение здесь измеряется абсолютной разницей двух относительных ошибок,
его нельзя смешивать с прежним отношением сеточных ошибок Бюргерса.
Для RMS использовать 2048 новых фиксированных LHS-точек x,t
с seed=20261022, общих для всех материалов. Параметры при дифференцировании
фиксированы, коэффициент и его координатный граф сохранены.

Проверить энергетическое затухание и положительность как диагностику,
не подменяя ими независимую ошибку. Сохранить каждую пару, каждый срез и
каждый неуспех. Усреднение по материалам не может скрыть провал одного.
Порог применяется к худшей паре; итог — число полных успехов из трёх
общих сетей, дополнительно доля успешных финальных пар из 231.
Исходные 13 пар показывать отдельно от дополнительных 64. Всего ожидается
348 пар-срезов: 3 модели × (4 исходных среза × 13 пар + 64 дополнительных
финальных пары). Передаче входов в FP32 сопоставить исходные значения
CSV и сохранить ошибку квантования; не объявлять её тождественно нулевой.

## Контроли и окончание

Сравнить с явным решением для постоянного c=1/8, применённым ко всем
материалам. Это контроль игнорирования входной функции, не конкурент,
обученный с равным бюджетом. Дополнительно для каждой обученной модели
оценить подмену её входа a,b нулями, сохраняя истинные эталоны: это
диагностическая абляция, не новая обученная ветвь. Неудачная полная модель
не становится успешной из-за улучшения над этой абляцией.

Окончание — три исхода либо ошибка/таймаут; цели не менять. Успех на
231 финальной паре не сертифицирует весь непрерывный квадрат и тем более все c(x).
Случаи с постоянной модой, большим числом мод, табличными произвольными
входами и скачками остаются за пределами этого одного опыта.
Время обучения, предсказания, пиковая память и число замыканий сохраняются
как стоимость способности; ускорение этим опытом не проверяется.
