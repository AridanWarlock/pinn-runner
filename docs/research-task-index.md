# Краткий список текущих задач

## Цель и использование

Новой сессии нужен актуальный вход в работу, а не номер завершённой задачи.
Команда читает Backlog через CLI и возвращает ограниченную страницу карточек:

```sh
python3 -B -S scripts/research.py tasks
python3 -B -S scripts/research.py tasks --limit 5 --skip 5
python3 -B -S scripts/research.py tasks --status 'In Progress'
python3 scripts/research.py task TASK-21 --criteria
```

По умолчанию исключены Done и Deferred. Порядок задаёт сама доска с сортировкой
по приоритету; команда не переставляет задачи и не выбирает поручение. Размер
страницы по умолчанию 5, допустим от 1 до 20; смещение неотрицательное.
`--status` задаёт один точный статус доски, включая Done или Deferred для явного
поиска. `--board` позволяет указать другой checkout для проверки.

Карточка содержит название, статус, приоритет, зависимости, ссылки на требования
и число выполненных критериев. История, план, заметки реализации и сами критерии
не включаются. После выбора задачи подробные критерии доступны через `task`.
Математические документы сохранены полностью и открываются по необходимости.

## Контракт и ограничения

Выход: `contract: 1`, `kind: task-page`, `tasks`, `limit`, `skip`, `next_skip`
и `total`. Следующая страница запрашивается с возвращённым `next_skip`.
Значение null означает, что CLI не сообщает следующую страницу или общий счётчик;
счётчик не угадывается. При изменении доски между страницами список нужно
прочитать заново: это живые данные, а не транзакционный снимок.

Для ссылок на требования список обогащается краткими карточками. Изменение
названия, статуса или приоритета между этими чтениями вызывает ошибку с просьбой
повторить команду. Остальные конкурентные изменения не исключены. Поле
`board_ready` отражает только готовность, объявленную Backlog: оно не разрешает
автоматически запускать обучение, менять настройки или обходить зависимости.
Перед началом работы остаются обязательными инструкции Backlog и требования задачи.

Неподдерживаемый JSON-контракт, дубли ID, отсутствующая готовность и неверная
пагинация вызывают ошибку. Проверка выполняется до вывода результата. Неверные
границы страницы отклоняются до вызова Backlog. Команда не меняет файлы проекта,
не обращается к Windows и не импортирует численные библиотеки.

Это завершает текущий блок инфраструктуры знакомства с проектом. Новых команд
без конкретной потребности добавлять не следует: дальше приоритет у поручения
пользователя и исследовательских задач текущего стека.

## Проверка реализации 2026-10-17

Профильный набор: 48 тестов пройдено. Общая быстрая проверка `scripts/check.py`:
Ruff, форматирование, strict mypy и 733 CPU-теста пройдены; 50 e2e исключены.
Полный набор в этом небольшом блоке не повторялся. Проверены ошибки контракта,
смена карточки между чтениями, фильтр, границы страницы и отсутствие истории.
Реальная доска обойдена четырьмя страницами по две карточки: 7 разных задач без
повторов, запуск с `-S` без Torch/NumPy. Windows и GPU не использовались.
