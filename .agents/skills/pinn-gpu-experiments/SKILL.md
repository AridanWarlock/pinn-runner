# CUDA-эксперименты pinn-runner

Работай из корня репозитория. Правила SSH, PowerShell, обязательного каталога
Windows и временных файлов заданы в `AGENTS.md`; не обходи их. GPU-обучение
на Mac запрещено. Скилл не расширяет поручение пользователя.

Перед новым типом операции открой нужный раздел
[API очереди](../../../docs/research-workflow-api.md). Используй имеющиеся команды,
не создавай отдельный SSH-запуск и вторую блокировку. Протокол фиксирует отдельные
SHA протокола и исходников.

Цикл через `python3 scripts/research.py`:

1. `plan --manifest PATH`: проверка матрицы и бюджета без GPU. Каталог относится
   к текущему инструменту; он не сертифицирует произвольную старую ревизию.
2. Опубликуй необходимые изменения и протокол в рамках разрешённой работы.
   `submit --protocol-commit FULL_SHA --protocol-path PATH --job-id ID`
   использует опубликованные объекты. Не подменяй зафиксированный SHA новым HEAD.
3. Проверяй `status --remote --job-id ID`. Во время обучения выполняй независимую
   работу на Mac. Не меняй среду или измеряемый снимок, не запускай конкурирующее
   измеряемое обучение. Выбирай частоту проверок по длительности задачи.
4. `collect --remote --job-id ID --output NEW_DIRECTORY` проверяет полноту и
   сохраняет компактный пакет. `compare --bundle NEW_DIRECTORY` проверяет
   целостность и парные критерии. Подробности запрашивай по конкретному вопросу.

При сбое начни с `diagnose --remote --job-id ID`; добавляй лишь нужный ограниченный
хвост `--log run --lines 10 --max-bytes 2048`.
[Правила диагностики](../../../docs/research-diagnostics.md).
Обрыв SSH не означает остановку или успешное обучение. При `unknown` выясни
происхождение и владельца; не повторяй запуск с новым ID, не удаляй блокировку
и не завершай процесс по одному PID. Отмена: `cancel --job-id ID`, затем
подтверждение статуса. Частичный пакет не исправляй ручной записью `bundle.json`;
старый пакет пересобирай из отчётов в новую папку без обучения.

В отчёте укажи SHA/среду, полноту серии, абсолютное качество отдельно от парного
сравнения, время обучения и предсказания с режимом измерения. `completed`,
`--probe` и короткая проверка транспорта не доказывают качество PDE.
После команд закрой соединения; отсоединённая задача может продолжать работу.
