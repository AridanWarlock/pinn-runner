## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Технический контракт часов сам по себе не доказывает качества. Нужно проверить одну общую модель на исходных физических гипотезах коэффициента, сохранив поздние нормы: две предыдущие серии дали 0/3, и улучшение общей невязки не спасло позднее поле. Модель часов изучает форму при опорном масштабе, остальные масштабы обрабатываются точной физической симметрией.
