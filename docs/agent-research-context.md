## Переменная теплопроводность

Единичный квадрат, время[0,1], теплоёмкость1, известная kappa:

$$
\partial_t T-\nabla\cdot(\kappa\nabla T)=f,\qquad
\kappa=\frac18\left(1+\frac\beta2(x+y)\right),\quad\beta\in\{0,1\}.
$$

Дивергенция содержит оба слагаемых:

$$
\nabla\cdot(\kappa\nabla T)=\kappa\Delta T+\nabla\kappa\cdot\nabla T,
\qquad j=-\kappa\nabla T.
$$

Нулевой поток эквивалентен нулевой нормальной производной только при
положительной kappa; ненулевые условия так заменять нельзя.
Neumann-метрика производной и физический поток — разные величины.
Параметры сети отделены от физических буферов таблицы.
Хеш точек/меток не описывает PDE: нужны physics/beta и собственный SHA
самостоятельного источника каждой ветви. Между разными beta PDE различны.

Аффинная kappa точно воспроизводится многолинейной таблицей в вещественной
арифметике; выбранные двоичные узлы/значения точно хранятся в FP32.
Неаффинная таблица задаёт другое поле kappa_h и другую PDE. Для квадратичного
примера ошибка коэффициента порядка h², невязка прежнего поля порядка h;
среднее тепло может скрывать локальную операторную ошибку.
[Постановка](variable-conductivity-experiment-draft-2026-10-18.md),
[интерполяция](conductivity-interpolation-study-2026-10-19.md).

Полиномиальные Neumann-признаки — два независимых признака q/P:

$$
q(s)=3s^2-2s^3,\qquad P(s)=16s^2(1-s)^2.
$$

Не приписывать им ограничение третьей граничной производной косинуса.
Это другая функция признаков; аналитическое правило производной q/P было
проверено отдельно, но в TASK-33 использовалось eager/autograd.
[Представление и граничные производные](neumann-polynomial-representation.md),
[аналитическое правило](neumann-analytic-pullback.md).

При точных IC/нулевом потоке непрерывная ошибка ограничивается временным
интегралом невязки. Оптимальная достаточная пространственно-временная
константа2T/pi; одной малой RMS невязки недостаточно для наших относительных
целей. Явный постоянный по пространству контрпример это показывает.
[Вывод, ненулевой поток и19 проверок](conductivity-error-control-2026-10-19.md).

## Другие PDE

Перенос со скоростью1: вход слева, выходящая характеристика справа.
Нулевое выходное условие противоречит точному полю sin(pi·(x−t)).
В текущей реализации hard_initial_dirichlet требует всех граней;
для этого переноса используется исходный soft режим. PDE-невязка не видит
постоянного смещения поля; начальные/входные данные определяют его.

Бюргерс: вязкость0,1, известный источник для exp(−t)sin(pi·x),
нулевые значения на обоих концах, время[0,0,5]. В весовом градиенте нужны
оба множителя нелинейности:

$$
\partial_w(u u_x)=(\partial_wu)u_x+u\,\partial_x\partial_wu.
$$

Отсоединение первого множителя сохраняет невязку, но меняет градиент
реальных сетей минимум на12,25%. Проверка только точного нулевого
функционала вырождена. CPU8/8 не считать CUDA-приёмкой.

Энергия ошибки Бюргерса содержит производную точного поля; переносить
сжимающий аргумент теплопроводности без этого члена нельзя. Нулевые
граничные ошибки — существенная предпосылка; при soft остаются граничные
слагаемые. Гладкий вынужденный пример не проверяет ударные слои.
[Доказательства и12 квадратурных контролей](nonheat-stability-context-2026-10-19.md).
