# Ошибка температуры и ошибка граничного оператора

Для Дирихле температура на стенке задана непосредственно. Для Неймана задана
её нормальная производная; для Робина — линейная комбинация значения и
производной. Поэтому одна ошибка температуры на стенке не проверяет все эти
условия одинаково.

## Что означают поля отчёта

`boundary_temperature_rmse` — ошибка предсказанной температуры на граничных
точках относительно аналитического эталона. Для сопоставления прежних данных
`boundary_rmse` временно остаётся псевдонимом с тем же смыслом. Старые критерии
текущей зарегистрированной серии не меняются задним числом.

`diagnostics.boundary_operators` в обычном бенчмарке и `boundary_operators`
каждого среза в измерителе времени содержат **отдельную запись на каждую
настроенную грань и условие**. Запись указывает поле, тип условия, ось, сторону,
число точек, RMS и максимальную абсолютную ошибку оператора. Эти величины
считаются без знания точного решения во всём объёме: достаточно заданных
физических граничных данных.

## Проверяемые выражения

Пусть h — заданное значение на грани, n — внешняя единичная нормаль, c —
положительный коэффициент теплопроводности. На нижней грани нормаль по оси
равна −1, на верхней +1. Ошибки определены так:

$$
r_D=u-h,
\qquad r_N=\partial_n u-h,
$$

$$
r_R=\alpha u+\beta\partial_n u-h,
\qquad r_q=-c\,\partial_n u-h.
$$

Последняя формула — заданный наружный тепловой поток. При переменном c здесь
умножается нормальная производная температуры, а не дифференцируется произведение
c·u. Это следует из закона потока; дивергенция потока в объёмном уравнении —
отдельная операция. Поддерживаются числовой c, параметр семейства и поле
коэффициента из `Problem.coefficients`.

Разные операторы могут иметь разные единицы и масштабы. Поэтому диагностический
код не складывает ошибки Дирихле, Неймана, Робина и разных физических полей
в одну универсальную RMS. Для назначения порогов нужно учитывать конкретную
постановку и размерности коэффициентов.

## Независимость и выборка

Используется физическое поле и обычное автоматическое дифференцирование,
с отключением готовых правил ускоренного вычисления производных. Проверка
не обращается к обучающей функции потерь или аналитическому эталону.
Данные граничных условий и коэффициенты берутся из публичной постановки задачи.

На каждой грани формируется отдельная воспроизводимая выборка внутренних
точек грани; касательные координаты не лежат на других гранях. Включены
начальное и последнее время. Ось границы, пространство, время и параметры
семейства учитывают физические интервалы, включая смещённые области.
Если в выбранном типе чисел внутренние точки грани вообще не представимы,
выдаётся явная ошибка. Углы здесь не подсчитываются дважды; их совместимость
проверяет отдельная система точных ограничений. Эти диагностические точки
не участвуют в обучении.

Это конечная выборка, не непрерывный сертификат. Для строгой математической
оценки нужны дополнительные предпосылки и контроль ошибок интегрирования.
Измеренное время обучения не включает эти проверки; время отдельной оценки
может включать их и записывается отдельно.
