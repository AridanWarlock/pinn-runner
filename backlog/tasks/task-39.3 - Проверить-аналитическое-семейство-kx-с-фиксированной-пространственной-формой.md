## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Добавить пространственную изменчивость отдельно от разнообразия форм функций. Первый кандидат: k(x)=a[1+2x(1-x)], одинаковое начальное поле 4x(1-x), источник нулевой. Изменяется масштаб a, форма пока фиксирована; это не решение для произвольной k(x).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Аналитическое решение и дивергенция потока независимо проверены; неверный оператор без производной k обнаруживается.
- [x] #2 До обучения закреплены семейство, диапазон a, новые гипотезы и абсолютные цели; поле аналитически зависит от a при одинаковых данных.
- [ ] #3 Общая сеть оценена на новых a без переобучения; качество и стоимость сопоставлены с предыдущей ступенью, ограничение фиксированной формы явно сохранено.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Проверить реальную FCN для k(x)=a[1+2x(1-x)]: дивергенцию, все градиенты, смешанные партии и конечные разности; обнаружить потерю производной k. 2. Закрепить аналитическое семейство, диапазон a, гипотезы и цели до обучения. 3. Провести CPU и зарегистрированный численный CUDA-допуск. 4. Отдельным следующим блоком включить семейство в оценку качества и файловый допуск, затем ограниченную серию общих моделей. В текущем блоке обучение качества этого семейства не запускается.
