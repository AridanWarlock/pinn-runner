## Ограничения, которые нельзя потерять

Локальное c(x) и один эффективный коэффициент не кодируют всё решение.
Два датчика определяют только выбранное семейство. Девять редких датчиков
могут пропустить материал с разницей поля 0.1175; один шаг уточнения кода
17→33 тоже может дать ложную неизменность. Есть непрерывная энергетическая
граница ошибки решения через равномерную ошибку log(c); начальная норма
в знаменателе. Конечные точки и средняя невязка не дают этого сертификата.
Гладкий контрпример проходит исходные 13 материалов, но имеет ошибку 9.65%
в другом материале. Не выдавать успех конечной проверки за весь квадрат.

Domain.grid строит полное произведение параметров **до** LHS; десятки
входных значений функции так не масштабируются. Внутренний PointCloudData
уже принимает согласованные строки: 128 кодов ×129 признаков проверены
в 4.66 MB. Однако существующий LHS перемешивает признаки независимо.
Для набора функций нужен выбор целого кода, затем физических координат;
публичный новый контракт ещё не реализован. Для двух a,b барьер не мешает.
