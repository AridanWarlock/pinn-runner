выбранной задачи. Этот файл — сводка численных исследований.

выкладки и исходные отчёты сохраняются по ссылкам ниже.

## Что применяется сейчас

- Основное представление — `identity`, с проверенной проекцией.
- Начальный фон — `hard_background: auto`: числовые данные используют
  начальное поле, функции граничных данных сохраняют общий фон.
- Пространственные признаки выбираются явно. Для них обычный `eager`
  остаётся по умолчанию; `neumann_analytic` — отдельный опытный переключатель
  точных производных полиномиальных признаков.
- Основной `tolerance_change` сохраняет 1e−9;1e−12 исследуется явно.
- Torch2.1/cu118 не обновлялся. Полного профиля GPU-ядер наWindows нет:
  CUDA-активность `torch.profiler` недоступна.
