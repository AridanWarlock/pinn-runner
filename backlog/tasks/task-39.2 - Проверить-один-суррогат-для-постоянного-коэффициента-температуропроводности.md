## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Самый простой опыт должен проверить саму схему: одна модель получает значение k и предсказывает решения для новых k без нового обучения. Использовать аналитическое семейство с одинаковыми начальными и граничными данными.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 До обучения опубликованы аналитическое семейство, диапазон k, разбиение гипотез, бюджеты, абсолютные цели и критерий окончания.
- [x] #2 Одна общая модель оценена без переобучения на заранее выделенных новых k; проверены поле, невязка, начальные и граничные данные, сохранены все исходы.
- [x] #3 Есть несколько начальных состояний сети, контроль игнорирования k, проверка сохранённой модели и исходное измерение полной стоимости; принято решение о следующем этапе.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Зафиксировать аналитическое семейство постоянного k и независимые гипотезы проверки. 2. Добавить ограниченную параметрическую оценку в прежний исследовательский путь, проверить реальные градиенты и файловый цикл. 3. Выполнить требуемые CPU-проверки и CUDA-допуск. 4. Опубликовать машинный протокол, провести ограниченную серию общих моделей и штатный collect/compare. 5. Сохранить качество, контроль игнорирования k, стоимость и решение о следующем шаге.
<!-- SECTION:PLAN:END -->
