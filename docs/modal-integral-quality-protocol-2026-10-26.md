# Один опыт: нейросетевой модальный суррогат формы коэффициента

Статус: заранее заданный протокол следующей серии TASK-39.5.4.
Машинные SHA и результаты указываются отдельно после регистрации и исполнения.

Гипотеза: общая сеть по форме b, обученная непрерывному PDE-функционалу
в уравновешенных модальных координатах, достигнет прежних физических целей
для k=a(1+x/b)² без переобучения между кодами (a,b).

## Зафиксированный кандидат

- Поле из [публичного контракта](quadratic-modal-contract.md), M=32,
  f=sin³(pi x), нулевые концы, нулевой источник.
- FCN [1,32,32,32,31], 3199 параметров, единственный вход сети b.
  Физический запрос сохраняет x,a,b,t; внешние часы не применяются.
- Единственная нормировка `mode_gap`: d_n=3*z_n/(n²−1).
  [Причина выбора](modal-objective-conditioning-2026-10-26.md) — отношение
  диагональных кривизн 116281 в сырых координатах, известное до обучения.
- Прежние 14 уникальных обучающих b, при A=0.15, диапазон b∈[1,2].
  Начальные проекции и физические веса готовятся квадратурой 256 в FP64,
  затем однократно переводятся в FP32. Учитель T(t>0) отсутствует.
- Обучается среднее по 14 формам от интеграла квадрата PDE-невязки
  без постоянного остатка отсечения. Пространственно-временная LHS-выборка
  не используется; `points_override=null` не означает 4096 физических точек.
- IC/BC не входят отдельными штрафами: они обеспечены представлением;
  их фактические ошибки округления всё равно оцениваются независимо.

Функционал равен непрерывной PDE-потере с точностью до постоянного остатка
при точных проекциях. Реальная подготовка проекций квадратурная;
численный допуск сравнивает порядки 256/512 и независимый интеграл 128×16.
Это не точная оптимизация старой суммы по 4096 точкам и не сравнение скорости
при одинаковом числе вычислений. [Перенос невязки к полю](modal-residual-transfer-2026-10-26.md)
остаётся дополнительной диагностикой, не заменой физических норм оценщика.

## Бюджет и окончание

Три независимых начальных состояния: seed 11,29,83. Каждая модель получает
500 полных Adam-обновлений с lr=0.001, weight_decay=0, стандартными betas/eps
у закреплённого Torch. Затем 500 внешних L-BFGS с lr=1, history_size=50,
max_iter=1, strong_wolfe, tolerance_grad=1e-7, tolerance_change=1e-12.
Срезы после Adam и после 250/500 внешних L-BFGS. Замыкания считаются отдельно.
Один шаг оценивает сразу все 14 форм; физических вызовов PDE по точкам нет.

Окончание — все три завершённые траектории либо подтверждённый сбой допуска,
неконечное значение или транспортный сбой с сохранением артефактов.
После просмотра качества не увеличивать бюджет, число мод или сетку форм,
не перебирать нормировки и не ослаблять пороги. Неполная серия не принимается.

## Независимая оценка

Прежние восемь новых кодов и четыре угла, сетка 101×101, 1024 фиксированных
контрольных точки PDE, шесть упорядоченных откликов. Эталон — прежний
независимый ряд из 64 мод; сравнение проекций при t=0 контролирует общий
остаток ряда отдельно. Между кодами веса неизменны. Для каждой модели
проверяются худшие, а не средние по гипотезам значения:

| Метрика | Предел |
|---|---:|
| Глобальное относительное поле | 0.02 |
| Финальное и худшее временное поле | 0.03 |
| Пространственная производная | 0.05 |
| Физический поток | 0.05 |
| PDE RMS | 0.02 |
| Отклик пары гипотез | 0.05 |
| Начальное RMS / граничный максимум | 1e-6 |

Научное принятие — 3/3 финальных моделей по всем целям при полном пакете.
Успешные технические тесты, малый интеграл обучения, идеальный проекционный
контроль или `completed` отдельно не принимают суррогат.
Время диагностическое: пользователь может одновременно использовать ПК.
Не заявлять ускорение или окупаемость.

## Порядок допуска

Публичный файловый цикл, восемь сценариев интегральной потери и контроль
вместимости 32 мод выполнены отдельно. Для нового пути обучения перед серией
нужен один короткий CUDA-цикл: 1 Adam + 1 внешний L-BFGS, независимые 12 кодов
и шесть откликов, штатные collect/compare и отрицательные проверки подмены
описания функционала/счётчиков в пакете. Короткое обучение не принимает качество.
Затем публикуются отдельные SHA исходников и машинного протокола серии.
