## Что изменилось

- `diagnose` читает только короткие метаданные; журналы добавляются явным
  параметром. Чтение хвоста ограничено байтами до декодирования и числом строк
  после. У каждого результата есть размер чтения, полный размер и признак усечения.
- Метаданные ограничены 64 KiB, отдельные сообщения — 500 символами. Повреждённые
  записи дают `unknown`, вложенные произвольные поля не выводятся.
- Локальная копия не используется для проверки Windows-PID на Mac.
- Однозначный отказ до создания процесса сохраняется как `failed/launch_rejected`.
  Сбой после возможного создания процесса не выдаётся за такой отказ;
  второй запуск с тем же ID запрещён.
- Сбор публикует `bundle.json` последним, с SHA-256 JSON и обеих CSV. `compare`
  проверяет запись и все файлы. Частично записанная папка остаётся непригодной
  для сравнения, вместо ложного успешного пакета.

## Передача и ограничения

Обычная точка входа — [agent-start](agent-start.md). При ошибке сначала
диагностика, затем только нужный хвост, а не полный журнал/отчёт. Сбой самого SSH
не доказывает остановки рабочего процесса. Без доступного транспорта состояние
Windows не восстанавливается по локальному PID.

Ранние пакеты без `bundle.json` пересобираются в новую папку из исходных
результатов; обучение повторять не нужно. Не дописывать маркер вручную и
не перезаписывать частичную папку. Код не выполняет автоматическую очистку,
перезапуск неизвестного процесса или повышение прав.

TASK-21; продолжение определяется новым поручением, не историческим планом
