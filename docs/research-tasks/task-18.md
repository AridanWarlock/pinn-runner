# TASK-18: Сравнить новый eager FP32 и старый runtime

## Цель и исходные требования

Само обновление может быть maintenance без ускорения; версии не смешиваем с новыми математическими стратегиями.

Статус, приоритет и зависимости читайте из короткой карточки, не из истории.

## Критерии результата

- Изолированный old/new eager опыт при одинаковом PDE/recipe
- Проверены derivative/checkpoint/resume и cold/warm performance на всех PDE
- Full CPU, CUDA и целевой Docker проверены до обновления зависимостей
