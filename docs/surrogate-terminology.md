# Терминология и обозначения суррогатного моделирования

Рабочий словарь долгосрочной программы TASK-39. Это математический язык,
а не окончательный API. Новые понятия сначала добавляются сюда с областью
применимости. Исторические отчёты не переименовываются автоматически.

## Цель

Суррогатный решатель один раз обучается на классе задач, после чего
предсказывает решения для новых гипотез без нового обучения. Веса общей
сети при переходе между гипотезами фиксированы. Отдельное обучение для
каждого коэффициента — прямое PINN-решение, но ещё не требуемый суррогат.

## Основные понятия

| Термин | Смысл |
|---|---|
| Контекст задачи | То, что фиксировано внутри семейства: оператор, область, время, источник, начальные и граничные данные |
| Гипотеза | Конкретный набор изменяемых физических входов; сначала это одна функция температуропроводности |
| Семейство гипотез | Заранее определённый допустимый класс коэффициентов и диапазон их изменения |
| Код функции | Конечное описание всей входной функции: параметры известного семейства, коэффициенты разложения или значения в датчиках |
| Общий суррогат | Одна обученная модель, принимающая код гипотезы и координаты запроса |
| Эталон | Независимое решение для оценки ошибки; на аналитических этапах — формула или контролируемый аналитический ряд |
| Новый материал | Новая функция коэффициента, а не только новые координаты уже знакомого поля |
| Приёмка способности | Подтверждение заранее заданной точности и границ применения на выделенных гипотезах |
| Окупаемость | Область числа гипотез, в которой полная стоимость суррогата ниже согласованной стоимости независимых решений |

Слово «материал» — краткое обозначение коэффициента в тепловых задачах.
Временная функция и полный набор коэффициентов также могут быть гипотезой.
Слово «гипотеза» не означает автоматически доказанное физическое утверждение.

## Обозначения

| Символ | Значение |
|---|---|
| d | Число пространственных измерений |
| x или вектор x | Физическая пространственная координата |
| t, t_f | Текущее и конечное время |
| Ω | Пространственная область |
| h, H | Одна гипотеза и допустимое семейство гипотез |
| k_h | Коэффициент температуропроводности гипотезы h |
| P | Фиксированный контекст семейства |
| T_h | Температурное поле, соответствующее гипотезе h |
| T_h* | Независимый эталон этого поля |
| z_h, E_m | Код гипотезы и правило кодирования с разрешением m |
| θ | Обучаемые веса сети; не физическая гипотеза |
| S_θ | Общий суррогат с фиксированными весами |
| r_θ,h | Физическая невязка предсказанного поля |

В формулах вектор координат обозначается жирным x. В одном измерении
используется обычный x. Значения температуры и конечное время не смешиваются:
температура обозначается T, конечное время — t_f.

$$
P=(\mathcal L,\Omega,[0,t_f],f,T_0,g),\qquad
h\in\mathcal H,\qquad z_h=E_m(h).
$$

Здесь оператор и фиксированные данные составляют контекст. Символ g
сокращённо обозначает весь набор граничных операторов и их значений.
Сначала h задаёт только k_h. Если источник, геометрия или условия тоже
меняются, это явно включается в гипотезу либо объявляется другим контекстом.

$$
\mathcal G_P:h\longmapsto T_h,\qquad
\widehat T_{\theta,h}(\mathbf x,t)=S_\theta(z_h,\mathbf x,t).
$$

Первая запись — точное отображение задачи в решение, вторая — приближение
общей сетью. Кодирование тоже вносит ошибку: одинаковые коды различных
коэффициентов нельзя исправить увеличением сети. Разрешение m относится
к представлению входа, а не к числу обученных моделей.

В текущем коде `domain.parameters` и `Coordinates.parameters` обозначают
физические входы гипотезы; `model.parameters()` возвращает обучаемые веса.
Совпадение слова `parameters` не означает совпадения этих математических ролей.

## Температуропроводность и оператор

В новой программе основной символ коэффициента — **k**, как в запросе
пользователя. Обозначения c и kappa в прежних отчётах остаются историческими.
Не следует автоматически трактовать c как теплоёмкость.

Начальная постановка — скалярная изотропная температуропроводность,
положительная и ограниченная на заданном пространстве-времени:

$$
\partial_tT_h-\nabla_{\mathbf x}\cdot
\bigl(k_h(\mathbf x,t)\nabla_{\mathbf x}T_h\bigr)=f,
\qquad 0<k_{\min}\le k_h\le k_{\max}.
$$

Она получается из физического баланса при постоянной объёмной теплоёмкости:

$$
C_v\partial_tT-\nabla\cdot(\lambda\nabla T)=Q,
\qquad k=\lambda/C_v,\qquad f=Q/C_v.
$$

Здесь λ — теплопроводность, C_v — объёмная теплоёмкость, Q — объёмный
источник. Если C_v меняется, простая замена на дивергенцию k неверна
в общем случае; такую физику вводят отдельной постановкой.

При пространственной зависимости необходимо сохранять оба члена:

$$
\nabla\cdot(k\nabla T)=k\Delta T+\nabla k\cdot\nabla T.
$$

Производные по физическим координатам берутся при фиксированной гипотезе
и её коде. Коэффициент в потоке при этом сохраняет зависимость от x.
Производные по компонентам кода не входят в пространственный лапласиан.
Если k зависит от времени, производная k по времени не добавляется
самостоятельно в этот оператор. Невязка определяется именно выбранной PDE.

Начально рассматриваются гладкие коэффициенты и освоенные области.
Скачки, интерфейсы, тензорная проводимость и переменная теплоёмкость
не объявляются поддержанными без отдельных математических условий и приёмки.

## Проверка гипотез

Температурное предсказание само по себе не подтверждает физическую гипотезу.
Для решения нужны наблюдения или заданный функционал, допустимое расхождение
и оценка ошибки суррогата. Рабочие исходы:

1. Совместимо с данными при заданной точности.
2. Несовместимо с данными при заданной точности.
3. Точности недостаточно для решения; требуется уточнение или независимый расчёт.

Третий исход не заменяется принудительным ответом «да» или «нет».
Совместимость с наблюдениями не является доказательством истинности модели.
