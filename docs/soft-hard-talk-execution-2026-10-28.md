# Исполняемый протокол soft/hard

Постановка, параметры и правила графиков заданы в
[математическом протоколе](soft-hard-talk-protocol-proposal-2026-10-28.md).
Пользователь согласовал отдельный контракт очереди и затем ограничил оставшуюся
работу 20 минутами. Поэтому машинный протокол сохраняет все шесть запланированных
запусков и 180 секунд на модель, но допускает только полный префикс пар.
Начало следующей пары запрещено, если от лимита 840 секунд рабочего цикла осталось
менее 420 секунд. Измерение стоимости выполняется после завершённых обучений.
Не запущенные seed указываются явно; частичная серия не выдаётся за полные n=3.

Независимая оценка проводится после обучения каждой модели; результаты не
используются для выбора гиперпараметров, остановки или числа следующих запусков.
Порядок фиксирован, ограничение применяется только по времени. Математический
backend eager/general и все настройки оптимизаторов неизменны.

Контракт9 использует общие GPU-lock и Windows Job Object, опубликованный SHA,
проверку неизменности снимка и стандартные collect/compare. Веточная версия worker
извлекается отдельно внутри C:\Projects\pinn-runner\.gpu-jobs и сверяется с Git-архивом;
файлы основного Windows checkout не заменяются. Удалённые посторонние untracked
файлы, обнаруженные до запуска, сохраняются.

Состояния line search не публикуются как checkpoints. Реальные длительности
и превышение 180 секунд сохраняются; строгое равенство времени не заявляется.
Проверенные окружения: Torch2.1.0+cu118, CUDA11.8, Lightning2.1.0,
NumPy1.26.4, SciPy1.11.4, RTX4070Ti, driver617.14. Обучение FP32, TF32 выключен.
