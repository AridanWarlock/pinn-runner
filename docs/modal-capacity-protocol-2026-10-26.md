# Контроль вместимости класса из 32 мод до обучения

Вопрос: проходит ли выбранное поле с точным начальным условием все прежние
цели, если коэффициенты d равны их идеальным начальным проекциям?
Ранее на 128 формах проверялся только остаток PDE. Этого недостаточно
для производной, потока, позднего поля и откликов между гипотезами.

Фиксируются 32 моды без перебора, f=sin³(pi x), прежние 12 кодов и шесть пар
из оценки приведённого времени. Для каждой запрашиваемой формы b проекции
известного f вычисляются квадратурой 256 в FP64; независимый порядок 512
контролирует квадратуру. Поле и физические метрики оцениваются в FP32.
Для отрицательного контроля весь декодер получает b=1.5 при прежнем физическом
коэффициенте PDE. Веса/таблица проекций заморожены до вызова оценщика.
Эталонные поля при t>0 не используются для построения коэффициентов.

Пороги неизменны: глобальное поле 0.02, финальное и худший временной срез 0.03,
производная/поток/отклик 0.05, PDE RMS 0.02, IC/BC 1e-6.
Окончание — один полный положительный и один отрицательный контроль,
без увеличения числа мод после просмотра результата.

Это **контроль вместимости представления**, не обученная PINN и не общий
суррогат: здесь проекции вычисляются отдельно для каждой формы запроса.
Успех не принимает родительскую TASK-39.5 и не заменяет три обученные модели.
Скрипт и срезы: `docs/experiments/2026-10-26-modal-capacity-*`.
