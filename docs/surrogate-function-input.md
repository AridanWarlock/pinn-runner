# Почему суррогату нужен код целой функции коэффициента

Это архитектурное ограничение будущих TASK-39.4/39.5, а не новый опыт обучения.
Для первых двух ступеней один скаляр однозначно задаёт всю функцию: постоянный
k либо известный профиль с масштабом a. При разнообразии форм передавать только
локальное значение k в запрашиваемой точке уже недостаточно.

## Контрпример для локального значения

Рассмотрим единичный отрезок, нулевой источник, нулевые температуры на концах
и одинаковое начальное поле для двух гипотез:

$$
T_t=\partial_x(kT_x),\qquad T(x,0)=\sin(\pi x),\qquad
T(0,t)=T(1,t)=0.
$$

Пусть a положительно, epsilon строго между нулём и единицей. Два гладких
положительных коэффициента и точка сравнения:

$$
k_1(x)=a,\qquad k_2(x)=a[1+\varepsilon\cos(2\pi x)],
\qquad x_0=\frac14.
$$

В точке x0 коэффициенты совпадают, но их пространственные производные различны:

$$
k_1(x_0)=k_2(x_0)=a,\qquad
k_1'(x_0)=0,\qquad k_2'(x_0)=-2\pi a\varepsilon.
$$

У обеих гипотез начальная температура в этой точке равна единице, делённой
на корень из двух. Но уравнение однозначно задаёт разные начальные скорости
изменения температуры:

$$
\begin{aligned}
\partial_t T_1(x_0,0)&=-\frac{a\pi^2}{\sqrt2},\\
\partial_t T_2(x_0,0)&=-\frac{a\pi^2}{\sqrt2}-\sqrt2 a\varepsilon\pi^2.
\end{aligned}
$$

Здесь использовано точное раскрытие дивергенции: kTxx плюс kxTx. Производная
коэффициента на обоих концах равна нулю; синус также даёт нулевые значения
второй производной на концах. Поэтому начальные данные и нулевые границы
совместимы и с первым временным условием. Коэффициенты гладкие и отделены от
нуля; в окрестности начального времени внутри области допустимо разложение:

$$
T_2(x_0,t)-T_1(x_0,t)
=-\sqrt2 a\varepsilon\pi^2 t+o(t),\qquad t\downarrow0.
$$

Следовательно, при достаточно малом положительном времени решения различны.
Однако входы x0, t и локальное k(x0) у гипотез одинаковы. Любая детерминированная
сеть только с этими входами выдаст одно и то же число для двух разных точных
решений. Это ограничение информации во входе, которое не устраняется более
долгим обучением, большей сетью или более точными производными.

Для примера a=0.1 и epsilon=0.2 дают одинаковое локальное k=0.1, но скорости
около −0.697886 и −0.977041. Совпадение текущей температуры и коэффициента
не означает совпадения дальнейшего решения.

## Следствие для будущего интерфейса

Вход общей сети должен различать гипотезы целой функции. Для этого нужен код z_h,
определённый независимо от запрашиваемой физической координаты:

$$
T_\theta(x,t,z_h),\qquad k_h(x)=\mathcal K(x;z_h).
$$

Первый аргумент — координата запроса; z_h — описание одной всей гипотезы;
оператор K восстанавливает коэффициент из кода. В консервативной невязке
пространственные производные берутся при фиксированном z_h. Компоненты кода
не являются дополнительными пространственными осями лапласиана.

В постоянном семействе кодом служит k. В семействе фиксированной формы — a.
Для косинусного контрпримера подходящим кодом внутри именно этого семейства
была бы пара a, epsilon. Это не универсальный код произвольной функции.

Добавление локального kx различило бы данный контрпример. Оно само по себе
ещё не доказывает достаточность входа для более широкого класса функций.
Будущий код следует выбирать вместе с допустимым классом коэффициентов,
его идентифицируемостью, правилами интерполяции и независимой проверкой новых форм.

Один z_h должен соответствовать одной целой строке гипотезы. Независимое
перемешивание его компонент при выборке может породить другой коэффициент;
это нельзя считать повторной выборкой той же гипотезы. Реализация такого
контракта и устранение полного декартова произведения признаков остаются
TASK-39.4. Этот текст не вводит новый API и не является приёмкой обученной модели.
