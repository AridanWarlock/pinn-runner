# Следующая проверка качества: форма коэффициента в приведённом времени

Перспективный протокол TASK-39.5.2. Запуск допустим только после завершения
технической TASK-39.5.1: численные проверки CPU/CUDA, защита сохранённого
правила и короткий файловый цикл. Этот документ записан до обучения качества.
Машинный протокол будет опубликован отдельно с точными SHA исходников и оценки.

## Одна гипотеза

Для семейства k=a(1+x/b)² с одинаковыми sin³(pi x) в начальный момент,
нулевым источником и нулевыми условиями Дирихле точная факторизация масштаба
и обучение формы на полном опорном времени могут обеспечить прежние
абсолютные цели общей модели. A=0.15; физический запрос остаётся (x,a,b,t),
а сеть получает (x,b,s), где s=(a/A)t.
[Доказательство и пределы применимости](surrogate-scale-as-clock-2026-10-21.md),
[публичный контракт](scaled-time-contract.md).

Это одновременно меняет класс модельных функций, число параметров и
распределение обучающих точек. Результат нельзя приписать только уменьшению
числа входов. Одинаковые seed не означают одинаковую инициализацию сетей
разной ширины входного слоя. Новая серия самостоятельна; данные предыдущих
отрицательных серий не объединяются с ней в одну статистику.

## Фиксированная матрица

- Одна FCN на каждый seed 11,29,83: три скрытых слоя по 32, tanh, 2273 параметра.
- 14 разных обучающих b из прежних 16 строк; во всех строках a=A. Физический
  диапазон a остаётся от 0.05 до 0.15. Для каждого b покрывается всё опорное
  время s от 0 до 1, а не прежний префикс, зависящий от a в строке.
- 4096 фиксированных точек уравнения, LHS по физическим x,t с целыми строками
  кода. Начальные/граничные данные задаются Problem, эталонные поля не обучают сеть.
- 500 Adam + 500 внешних L-BFGS; снимки 0,250,500, tolerance_change=1e-12.
  Значения потерь, скорость и начальные веса не подбираются после просмотра результата.
- Точность: FP32 сети, FP64 независимого аналитического ряда, TF32 выключен.

Оценка сохраняет прежние 12 физических кодов: восемь новых b при
 a=0.075/0.125 и четыре угла a=0.05/0.15,b=1/2. Метка четырёх углов
для новой серии — `corner`: два кода с a=0.05 непосредственно в обучении
не встречались, хотя b=1/2 обучались при A. Это не новая форма b.

## Цели и окончание

Каждая из трёх моделей оценивается с одними неизменными весами на всех кодах:
сетка 101×101, 1024 точки невязки seed 20261021, те же шесть пар отклика.

| Метрика | Максимум |
|---|---:|
| Общая относительная ошибка поля | 2% |
| Финальная / худшая временная ошибка | 3% / 3% |
| Относительная ошибка производной / потока | 5% / 5% |
| PDE RMS | 0.02 |
| Относительная ошибка отклика | 5% |
| Начальная RMS / максимум границ | 1e-6 / 1e-6 |

Все максимумы берутся по отдельным гипотезам/парам. Окончание — три полных
опыта либо подтверждённый сбой технического допуска/исполнения. Принятие
требует 3/3 по всем целям. При отрицательном результате сохраняются все
срезы и причины, без автоматического увеличения бюджета, ослабления целей
или перебора новых множителей. Время диагностическое: параллельное
использование ПК не позволяет делать выводы об ускорении или окупаемости.
