# TASK-39.4: проект контракта целых строк кода функции

Это ограниченный следующий шаг после научной приёмки TASK-39.3. Текст фиксирует
проект и математический смысл; наличие этого документа само по себе не означает,
что поля конфигурации уже поддерживаются или точность новых форм принята.

## Код и класс коэффициентов

Для первого контроля достаточно двух косинусных коэффициентов целой функции:

$$
z_h=(a,b),\qquad q_h(x)=a\cos(\pi x)+b\cos(2\pi x),\qquad
k_h(x)=\frac18 e^{q_h(x)},\qquad a,b\in[-0.7,0.7].
$$

Один вектор z_h задаёт один профиль на всём отрезке. Это не пара локальных
значений коэффициента в точках запроса. Класс положителен и ограничен:

$$
\frac18e^{-1.4}\leq k_h(x)\leq\frac18e^{1.4}.
$$

Внутри этого конечного класса кодирование точное: ошибки представления нет.
Произвольная функция в этот класс не обязана входить. Если позднее логарифм
коэффициента приближается конечным рядом с равномерной ошибкой epsilon, то:

$$
\|q-\widetilde q\|_\infty\leq\varepsilon
\quad\Longrightarrow\quad
\left|\frac{\widetilde k(x)}{k(x)}-1\right|\leq e^{\varepsilon}-1.
$$

Это оценка ошибки представления коэффициента, не температуры и не обученной
сети. Для такого расширения потребуется отдельный контроль этой ошибки.

Пространственные производные берутся при фиксированном коде:

$$
(k_h)_x=-\pi k_h[a\sin(\pi x)+2b\sin(2\pi x)].
$$

В невязке используются u_t, u_xx и этот градиент k. Производные u_aa и u_bb
не входят в пространственный лапласиан. Производная k на концах равна нулю;
начальный синус совместим с нулевыми границами и первым временным условием.
Этот класс уже использовался в численной подготовке TASK-38, но его общая
модель не прошла требуемую нынешней программой аналитическую приёмку.

## Предлагаемые поля

Имена и интервалы остаются в `domain.parameters`. Новый необязательный
`domain.parameter_rows` задаёт согласованные строки в порядке этих имён:

```yaml
domain:
  parameters:
    a: {interval: [-0.7, 0.7], points: 3}
    b: {interval: [-0.7, 0.7], points: 3}
  parameter_rows:
    - [-0.6, 0.36]
    - [0.0, 0.0]
    - [0.6, 0.36]
prediction:
  parameter_rows:
    - [-0.4, 0.16]
    - [0.4, 0.16]
```

При явном выборе строк узлы `points` осей параметров не перемножаются;
интервалы и порядок имён сохраняют смысл нормализации. Без этого поля старый
режим независимых осей остаётся прежним. Строки — непустая прямоугольная
таблица конечных чисел без bool и повторов. Число столбцов совпадает с числом
имён. Обучающие строки лежат в объявленных интервалах.

`prediction.parameter_rows` и прежний `prediction.parameters` взаимно
исключаются. В режиме обучающих строк частичный запрос независимых параметров
нельзя молча превращать в новые комбинации. Новые строки предсказания разрешены
при прежних именах, порядке и нормализации; выход за интервалы подчиняется
существующему явному `allow_extrapolation`. Нахождение внутри прямоугольника
интервалов не гарантирует принадлежности распределению обучающих гипотез.

## Выборка и размер данных

Сначала строится только физическая сетка, затем она пересекается со списком
целых строк. Для N физических узлов и H гипотез получается N H строк, а не
произведение числа узлов каждой компоненты кода. Временная сетка пересекается
с ними как прежде. Порядок: физический узел, затем запрошенная строка кода,
затем время. Порядок запросов должен сохраняться в выходных массивах.

При LHS пространственные координаты и время выбираются как раньше, а код
берётся целиком из списка. Для примера выше должна сохраняться связь b=a²;
независимая LHS по компонентам разрушает заданный список гипотез. Это контроль
согласованности выборки, а не утверждение, что остальные пары a,b математически
запрещены во всём косинусном классе.

Стоимость хранения физической сетки по-прежнему растёт с размерностью области;
устраняется только экспоненциальное произведение признаков кода. Это не решение
всех ограничений памяти. Обучающая невязка при N_c точках хранит N_c целых кодов.

## Сохранённая модель и обязательные контроли

Декодер функции задаёт публичный источник Problem, защищённый прежней проверкой
его идентичности. Имена входов, порядок и исходные интервалы нормализации также
сохраняют прежние проверки. Набор запрошенных гипотез может меняться; он не
должен перенормировать сохранённую сеть по минимуму и максимуму новых строк.

Нужны контроли высокой размерности кода без произведения признаков, сохранения
согласованных строк в IC/BC и невязке, воспроизводимой выборки, неизменности
таблицы при внешней мутации и отбраковки повреждённых запросов. Математический
допуск использует реальные сети и физические производные при фиксированном
коде; файловый цикл — новые строки, прямое воспроизведение весов и проверку
идентичности источника. Новое обучение качества форм относится к TASK-39.5,
а не к допуску представления и выборки.
