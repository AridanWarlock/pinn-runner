# Почему точность поля не заменяет точность отклика

Суррогат должен различать гипотезы о коэффициенте. Пусть T_i,T_j —
точные поля двух гипотез, v_i,v_j — их предсказания с общими весами,
e_i=v_i−T_i и e_j=v_j−T_j. Норма в формулах одна и та же для всех полей;
разность точных решений предполагается ненулевой.

$$
\Delta T=T_j-T_i,\qquad \Delta v=v_j-v_i,
\qquad
\frac{\|\Delta v-\Delta T\|}{\|\Delta T\|}
\le\frac{\|e_i\|+\|e_j\|}{\|T_j-T_i\|}.
$$

Если каждое поле известно с относительной ошибкой не больше epsilon,
получается достаточная оценка с коэффициентом чувствительности K_ij:

$$
K_{ij}=\frac{\|T_i\|+\|T_j\|}{\|T_j-T_i\|},\qquad
\frac{\|\Delta v-\Delta T\|}{\|\Delta T\|}\le\epsilon K_{ij}.
$$

При близких гипотезах разность может быть мала по сравнению с самими
полями. Тогда одинаковая цель точности каждого поля даёт слабую границу
для отклика. Общие веса могут коррелировать ошибки и улучшать разность,
но само использование общих весов этого не доказывает. Неравенство
является достаточной верхней оценкой, а не прогнозом фактической ошибки.

Следовательно, полевая цель 2% сама по себе не гарантирует отклик 5%.
Это объясняет необходимость отдельного параметрического критерия;
пороги текущего протокола не меняются. Вычисленные достаточные ошибки
не назначаются новыми целями обучения. Они также не означают, что поле
с большей ошибкой обязательно даст неправильный отклик.

Точное преобразование масштаба в приведённое время сохраняет физический
смысл этих пар. Отклики по форме b всё равно должны быть проверены
независимо: точная обработка a не обеспечивает точность сравнения форм.
